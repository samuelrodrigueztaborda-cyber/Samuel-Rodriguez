## 🚀 Proyectos

### 💈 BarberAg — Sistema de gestión para barberías

Aplicación web desarrollada como proyecto formativo del SENA, orientada a mejorar la gestión de una barbería mediante herramientas digitales.

**Funcionalidades contempladas:**
- 👤 Gestión de usuarios y perfiles.
- 📅 Agendamiento y administración de citas.
- 💳 Gestión de pagos y suscripciones.
- ⭐ Sistema de reseñas.
- 💈 Administración de servicios y barberos.
- 📊 Gestión administrativa e informes.

**Tecnologías:** HTML5, CSS3, Bootstrap, JavaScript, Node.js, Express y MySQL.

**Estado:** En desarrollo y pruebas.

### 🎓 LearnHub — Plataforma de cursos en línea

Proyecto de práctica enfocado en la maquetación de una interfaz web para una plataforma educativa.

**Tecnologías:** HTML y Bootstrap 5.3.

### 🛒 HidraMarket — Calculadora de inventario y ventas

Proyecto de práctica para aplicar lógica de programación y operaciones relacionadas con el cálculo de inventario y ventas.

**Tecnologías:** HTML y Bootstrap.
